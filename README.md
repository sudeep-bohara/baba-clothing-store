# Baba Clothing — Storefront Concept

A portfolio-first, interactive e-commerce website concept for Baba Clothing (@babaclothing.np).

## Status
Planning and initial implementation setup. This is a concept/demo, not an authorized production store.

## Goals
- Create a distinctive, premium streetwear/lifestyle storefront.
- Reflect the observed black-and-white identity, BA-style monogram, and “Your style, Your identity.”
- Showcase mixed fashion collections using clearly identified sample products until real catalogue data is supplied.
- Deliver a polished, responsive experience, especially on mobile.
- Present the concept to the brand owner before discussing production use.

## Planned experience
Home, Shop/collections, Product detail, Shopping bag, About, and Contact.

## Suggested stack
Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons. Confirm compatible stable versions during implementation.

## Important constraints
- Do not invent official prices, stock, shipping policies, payment methods, office address, contact details, or market coverage.
- Clearly label sample products, imagery, and prices as demo content.
- No real payment processing, customer data collection, or production order submission in the concept.
- Keep secrets out of Git. Never commit credentials or environment files.
- Work on a feature branch and open a pull request; do not push implementation directly to main.
