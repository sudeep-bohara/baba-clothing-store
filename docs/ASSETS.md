# Image Credits & Asset Manifest — Baba Clothing Concept

All photography in this concept is **demonstration content**. It does not depict Baba Clothing
inventory or campaigns, and must be replaced with owner-supplied assets before any public use.

Every file is licensed **CC0 1.0** or **Public Domain Mark**, sourced through the
[Openverse](https://openverse.org) API and stored locally in `public/images/` so the concept
renders without third-party hotlinking. All frames are displayed in monochrome, so mixed
sources read as a single campaign.

## How to replace an image

1. Keep the same filename and directory under `public/images/`, or
2. Add the new file and update the single path reference in `lib/media.ts` (campaign frames) or
   `lib/products.ts` (product frames).

Each reference carries its own `alt` text and `focal` point, so a replacement keeps its crop and
description in one place. If you overwrite a file in place, clear the image cache
(`rm -rf .next/cache/images`) so the optimiser does not keep serving the old photograph.
